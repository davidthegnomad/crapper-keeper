# Crapper Keeper 2.0

Version **2.0.0**. The web app is https://davidthegnomadorg.web.app/crapper-keeper/. Desktop installers are on the [v2.0.0 release](https://github.com/davidthegnomad/crapper-keeper/releases/tag/v2.0.0).

The desktop app is a window around that live site, plus on-device models. Install the new shell to get speech, the notes model, and the local tool API. The website itself updates as soon as hosting is deployed.

## What is new

- **View** opens Slate, Preview, and sticky notes inside the same window.
- **Ask** edits notebooks, chapters, pages, Slate, Preview, and stickies with a local notes model. Deletes need a clear request.
- **Vault** stores secrets with a passphrase. The passphrase is not saved. The vault is not exported and is not on the tool API.
- **RAG export** writes one Markdown file per page in a zip.
- **Local tool API** lets a program on this computer list, create, rename, and delete notebooks, chapters, and pages.
- **Minutes** turns a recording into a page with attendees, discussion, decisions, action items, and the transcript.

## First open on the desktop

The installer stays small. The first time you open the desktop app, it asks before downloading models:

- Speech: whisper.cpp `ggml-small` (Linux and Windows).
- Notes: Qwen2.5-1.5B-Instruct, about 1.1 GB, Apache-2.0.

Choose **Download** or **Not now**. Nothing downloads until you choose Download. Mac gets the notes model only. Apple has no official whisper.cpp build in this release, so Record is unavailable there. Ask still works.

Models are saved in the app’s user data folder, not inside the notebook.

## RAG export

Open a notebook. Click the download button in the title bar.

- **This page for RAG**
- **This chapter for RAG**
- **This notebook for RAG**
- **Notebook as one Markdown file**

The zip is `{notebook}-rag.zip`. Each page is `{notebook}/{chapter}/{page}.md`. A subpage sits in the parent page’s folder. HTML pages are plain text. The zip includes a `README.md`.

Each file starts with YAML: `title`, `notebook`, `chapter`, `page_id`, `source`, and `updated` when the page has a date. Characters that are unsafe in a file path, including `:`, become spaces. `Micah 6:8` becomes the folder `Micah 6 8`. The notebook name inside the file stays `Micah 6:8`.

Unzip it and point a Markdown indexer at the folder. [Workspace RAG](https://github.com/davidthegnomad/workspace-rag) indexes `.md` files and cites the path. Do not put the vault in that folder. This export never includes it.

## Local tool API

The desktop app listens on `127.0.0.1` and a random port. It does not accept connections from other computers. Open **Ask** and use **Copy token**. The same address is written to `ck-tool-api.json` in the app user-data folder. Treat the token like a password for this computer.

```bash
curl -s \
  -H "Authorization: Bearer YOUR_TOKEN" \
  http://127.0.0.1:PORT/v1/tools
```

Call a tool:

```bash
curl -s \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"list_notebooks","arguments":{}}' \
  http://127.0.0.1:PORT/v1/tools/call
```

Tools: `list_notebooks`, `create_notebook`, `rename_notebook`, `delete_notebook`, `list_sections`, `create_section`, `rename_section`, `delete_section`, `list_pages`, `read_page`, `create_page`, `update_page`, `delete_page`, `export_rag`.

A delete is refused unless the JSON includes `"confirm": true`. Sign in first. The page runs the write, so the API only works while the notebook window is open. Vault, Slate, Preview, and stickies stay on the Ask box. They are not on this API.

`export_rag` returns the Markdown files for one notebook. It does not include the vault.

## Minutes

In Ask, click **Minutes**, talk, then click **Stop**. Speech becomes text on this computer. The notes model fills four sections. A line is kept only when its words appear in the transcript. Invented names and decisions are dropped. The page title is `Minutes YYYY-MM-DD`. The transcript is at the bottom.

If no chapter is open, the page is created under a notebook named Voice notes and a chapter named Recordings. **Record** is the older voice note. It saves a tidied transcript. It does not use the minutes headings.

## Vault

View → Vault. Set a passphrase. Entries are encrypted in the browser (AES-GCM, PBKDF2) and stored for that Google account. The passphrase is not written to disk or Firestore. A wrong passphrase does not open the entries. Ask can create or delete a vault entry only while it is unlocked, and a delete asks you first. The model is not given the secret text in its notebook snapshot.
